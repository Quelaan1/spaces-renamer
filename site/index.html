About turning off SIP

Renaming works by loading a small plugin into the system process that draws Mission Control. macOS only allows that with System Integrity Protection off, which lowers your Mac's protection against malware.

The app checks everything for you and fixes what it can. Restarting into Recovery to turn SIP off is the one step you do by hand.

Install

$brew install --cask Quelaan1/tap/spaces-renamer

Or download the DMG from the releases page and drag the app to Applications. Then open it from the menu bar.

  1. Turn off SIP

    Restart into Recovery, open Terminal, run csrutil disable, and restart.

  2. Enable the arm64e preview ABI

    Click Enable & restart in the app's Diagnostics tab.

  3. Activate, then name

    Click Activate, then type a name for each desktop.
